# 拾日历 0.1.0 验证记录

本记录对应 2026-11-12 的 Tauri 迁移版本，替代旧 SwiftUI/JavaScriptCore 链路的验收结论。环境：Apple Silicon macOS，Node 24.18.0，pnpm 12.18.0，Rust 1.99.1，Tauri CLI 2.12.4 / Rust 2.12.5，仅安装 Command Line Tools。

## 已通过

- `pnpm run check`：oxlint、oxfmt 格式检查、严格类型检查、20 项测试、核心 ESM/声明和网页生产构建。
- 原有 12 项历法/调休测试保留，覆盖年界、除夕、闰月、2033 年、节气、官方休班、跨年、缺失年份、日期及导入校验等。
- 新增 8 项应用状态测试，覆盖月份边界、初始化与损坏缓存、离线更新回退、部分年份更新、导入失败、保存顺序及失败反馈、北京时间跨午夜和外部来源校验。
- Rust 3 项测试：状态原子写入及版本拒绝、旧偏好和缓存只读迁移、多屏/负坐标/Retina 定位。
- `pnpm run build:mac`：打包应用与 ZIP，校验本地临时签名；包含第三方许可文件。
- `pnpm run check:mac`：已打包应用的真实 WKWebView 渲染 42 格月历，核对春节农历和补班样例，通过 Rust IPC 检查窗口显示、收起和重新打开。
- Tauri 开发模式实际启动前端服务与应用，完成相同 WebView 冒烟验证。
- 此前 Tauri 迁移时的 Mac CUA 实际操作：切月、回到今天、方向键选日、进入设置、Esc 返回及收起。读取到来自 `tauri://localhost` 的真实界面。
- 浏览器实际检查：年月跳转、2028 年“调休未收录”且无休班角标、深色偏好刷新后保留；1280px 桌面与 320px 触控窄屏均显示 42 格、无横向溢出，项目介绍位于首屏后。
- 核心分发干跑确认包中不存在旧 `apple-entry` 声明，构建会清理残留产物。
- 依赖审计当前结果为 0 项漏洞；此项不是对依赖安全性的全面保证。

## pnpm / Oxc / Tailwind 接入验证

- 使用 pnpm 12.18.0 清理旧依赖目录后安装，再次执行 `pnpm install --frozen-lockfile` 成功；既有直接依赖版本保持一致，工作区内部包改为 `workspace:*`。
- oxfmt 全项目处理 55 个支持的文件，随后格式检查通过；导入、package.json、脚本、Tailwind、JSDoc 及嵌入代码格式化均开启。对 15 份 JSON/TOML 核对内容，只有 package.json 元数据列表有排序，调休快照与配置值保持一致。
- oxlint 以不允许警告模式通过，自动 JSX 转换、旧浏览器数组 API 和交互 ARIA 网格的规则取舍已记录在 README。
- Tailwind 工具类实际生成；浏览器确认头部 flex 布局、导航间距、42 格月历、方向键和 PageDown 后焦点跟随；320px 触控深色视图无横向溢出，介绍保持在首屏之后。
- 许可证脚本通过 pnpm 生产依赖树收集 75 个前端依赖路径，已在干净隔离依赖布局下运行；pnpm 审计当前结果为 0 项漏洞。

## 五色圆润界面复验

- 用户确认 Mac 紧凑上下、宽屏网页双栏；共享界面使用红绿蓝黄紫五色语义和圆角面板。
- 检查 1280×900、978×606、390×844 深色、320×780 与 400×660 内容区，以及春节、未知年份、设置和跨年元旦网格；日历均保持 42 格，无横向溢出。320px 窄屏保留正常纵向滚动。
- 截图禁用过渡动画后再检查，避免选中框退场的中间帧造成双选误读。400×660 截图为浏览器模拟 Mac 内容样式，手机图为浏览器触控仿真。
- 独立视觉审查的完整矩阵认可布局、留白和五色语义，提出浅红底小字对比度问题；修正后该项获 resolved，verdict 为 ship，结论仅覆盖该修复及明显回归检查。
- 浅色休假红使用 `#cf3049`，在 `#fff0f2` 上为 4.55:1；相邻月休假格的农历字色也使用该状态色，保持可读。未收录年份仍以文字明确提示。
- 本轮 CUA 未能读取正在运行的开发窗口，不将其写成真实鼠标或完整辅助功能验收。程序化 Mac 验证使用真实 WKWebView，冒烟实例跳过持久化并与正常开发实例隔离。

## 验证边界

- 缺少完整 Xcode、iOS SDK 和 CocoaPods。官方 iOS 初始化尝试因 CocoaPods 缺失停止，尚未生成可验证的 Xcode 工程，未编译 iOS、运行模拟器或真机，也未运行 XCTest。
- 手机截图来自浏览器尺寸及触控仿真，不代表 iOS 安全区域、动态字体、横竖屏、后台恢复和辅助功能已验收。
- Mac 本次未逐一覆盖所有菜单栏鼠标、多显示器实机、导入面板、剪贴板权限与外部浏览器跳转路径；相关状态逻辑与坐标算法有测试，完整实操仍需补齐。
- VoiceOver 完整朗读路径尚未验收。生产 WebView 已运行，未做 Safari/Chrome 多版本兼容矩阵与长期驻留性能测试。
- 应用仅在 arm64 macOS 本机验证，配置最低 macOS 13 / iOS 16；不据此声称所有最低版本均已实测。
- 当前为 ad-hoc 临时签名，没有 Developer ID、Apple 公证、App Store 或 TestFlight 分发。
- Web 可查询已加载的离线数据，未实现首次加载或刷新离线缓存。
- Impeccable 检测器因缺少可选 HTML 解析模块而退化为正则扫描，未报告匹配项；结果不能替代浏览器与原生界面检查。

## 本地复验

```sh
pnpm install --frozen-lockfile
pnpm run check
pnpm run check:native
pnpm run build:mac
pnpm run check:mac
```

构建、截图、CLI 输出与临时验证目录保存在本机 `work/`，应用及 ZIP 在 `outputs/`，均不提交 Git。网页截图示例见 `docs/images/五色月历-网页.png`、`docs/images/五色月历-菜单栏布局.png` 与 `docs/images/五色月历-手机深色.png`。
