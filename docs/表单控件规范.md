# 表单控件规范

月历与设置共用一套表单视觉和状态规则。尺寸由 `packages/calendar-ui/src/form-theme.ts` 统一生成 CSS 变量；Radix Primitives 负责选择、开关、标签、菜单及单选组交互，原生按钮和输入保留系统语义。全部控件通过 `Calendar*` 组件封装，外观与透明触控区域使用 Tailwind，不再维护 Ant Design 主题或覆盖样式。接口与分层见[组件与样式架构](组件与样式架构.md)。

## 尺寸与间距

| 控件或布局                             | 统一规则                                                 |
| -------------------------------------- | -------------------------------------------------------- |
| Select、文本输入、普通按钮、颜色选择器 | 可见高度 28px、圆角 8px                                  |
| 控件文字与表单标签                     | 13px，控件行高 20px                                      |
| 字段与按钮横向内边距                   | 8px                                                      |
| 同行控件间距                           | 8px                                                      |
| 表单行间距                             | 12px                                                     |
| 分段选择                               | 外框高 28px、内边距 2px、选项高 24px，选中项使用面板底色 |
| 开关                                   | 轨道 36×20px、白色滑块 16px，开关使用其自身的圆角形态    |
| 年份与月份                             | 宽 78px / 62px，下拉图标 13px，保留完整年月文字          |
| 下拉列表项                             | 桌面最小高 32px，触控最小高 44px                         |

主题预设是包含色块的选择卡片，保留其独立布局，不强制压成 28px。说明文字维持 12px，辅助提示维持原有次级层级。

## 状态与颜色

- 常态使用主题的中性控件底色；悬停使用 `--control-hover`，按下使用 `--control-active`。状态只改变颜色，不改变边框厚度、位置或尺寸，不引入缩放和点击光圈。
- 按钮使用 `CalendarButton` 的普通、文字、图标、月份导航、今天和主题预设外观；布局类只负责尺寸和排版，不分别覆盖悬停色。底色、边框和选中描边绘制在同一层，选中主题的描边在悬停、按下时保持一致；加载图标覆盖原标签并保留其占位，避免按钮和相邻操作跳动，加载中不响应悬停或重复提交。
- 过渡统一为 130ms；减少动态偏好继续禁用过渡与动画。
- Select 选中项保持普通文字、透明底和灰色小勾；鼠标悬停或键盘活动项使用统一中性底色，不用蓝色选中填充。鼠标点击不产生焦点光圈，键盘操作显示 1px 中性细描边。
- 按钮、开关、分段选择的键盘焦点使用 1px 中性细描边；文本输入与颜色选择器获得焦点时同样显示细描边，输入光标使用强调色。
- 开关开启态保持强调色派生底色，悬停、按下分别使用 `--leaf-hover`、`--leaf-active`，关闭态使用独立的中性轨道及悬停/按下派生色，可交互状态下白色滑块在开、关两种轨道上均达到 4.5:1 对比度，保持开关状态易辨认。按钮和选项不因此变为蓝色填充。
- 错误输入显示红色细描边并保留具体错误说明；警告输入使用黄色细描边。校验失败继续禁用提交，不覆盖已保存值。
- 禁用状态只做一次 50% 弱化，使用弱化文字色，不响应悬停或按下；禁用选择器不会展开。保留原生 disabled、label、radio、switch 和键盘语义。
- `color-theme.ts` 为三套主题与自定义强调色生成悬停、按下配色，并验证主要文字、次要文字和操作文字在这些底色上的对比度不低于 4.5:1。占位文字使用满足同一标准的次要文字色，开关白色滑块与轨道也保持可辨对比。

## 触控与交互

可见样式保持一致，点击区域扩大到至少 44px：Select 和文本输入使用较大的透明外层，按钮、开关和分段选择保留原生控件，由透明伪元素扩大命中区域；颜色选择器扩大透明内边距。表单行相应预留 44px 高度，避免触控区域相互遮挡。320px 触控月历收紧容器间距，仍保持完整年月与同一行操作。

按钮只有鼠标指针触发悬停；触摸只保留按下反馈，松开后恢复原态。窗口失焦时清除鼠标悬停状态，避免菜单栏面板重新打开时保留底色。键盘细描边围绕可见控件绘制，不围绕扩大的透明点击区。

下拉继续支持方向键、回车、Esc 分层关闭、点击外部和窗口失焦关闭。文本输入继续支持原生编辑、回车提交与非法格式拦截。开关的菜单栏入口保护保持有效；颜色选择器仍使用系统面板和既有忙碌状态保护。

浏览器检查覆盖 Mac 内容尺寸、宽屏网页、浅深色和 320px/390px 触控模拟。Mac 打包后继续通过真实 WKWebView 冒烟验证；这些检查不代表 iOS 设备或系统颜色面板已完成验收。
