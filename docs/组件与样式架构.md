# 组件与样式架构

共享 UI 使用 Radix Primitives＋Tailwind CSS 3，Mac、后续 iOS 与网页版复用同一套封装。此次迁移保留既有视觉和交互，不更换日历的数据模型、配色算法或平台能力接口。

## 分层与组件

| 层次或封装            | 职责                                                           |
| --------------------- | -------------------------------------------------------------- |
| `CalendarButton`      | 原生按钮、外观变体、鼠标悬停、键盘焦点、加载占位及防重复操作   |
| `CalendarInput`       | 原生文本输入、输入法、表单提交、错误关联和透明触控区域         |
| `CalendarColorInput`  | 系统颜色面板、色块外观及原生悬浮窗交互协调                     |
| `CalendarSelect`      | Radix Select；保留字符串/数字值类型、列表、键盘选择与分层 Esc  |
| `CalendarSwitch`      | Radix Switch；受控状态、加载反馈、禁用与 44px 透明触控区域     |
| `CalendarSegmented`   | Radix Radio Group；受控单选、方向键、Tab 和读屏语义            |
| `CalendarTabs`        | Radix Tabs；按需挂载，访问后保留草稿与滚动位置，隐藏非活动面板 |
| `CalendarContextMenu` | Radix Context Menu；日期菜单、焦点、Esc、窗口失焦收起          |
| `form-theme.ts`       | 统一控件几何值，通过根 CSS 变量提供给 Tailwind                 |
| `color-theme.ts`      | 五色语义、三套预设、明暗模式、自定义强调色和对比度规则         |
| `calendar.css`        | 全局主题与基础规则、复杂日期状态、伪元素、动画和系统偏好       |

业务组件只调用 `Calendar*` 封装，Radix 导入集中在封装实现中；不向业务暴露底层库的主题、样式或多选配置。所有组件从 `@i-calendar/ui` 导出，React 仍作为共享包的 peer dependency，Radix 是共享 UI 自身的运行依赖。

普通布局、字号、间距、边框、状态和响应式直接使用带 `tw-` 前缀的 Tailwind 类。主题色与尺寸引用已有变量，不复制配色算法。Preflight 保持关闭，避免全局重置改变既有页面、原生输入和菜单栏尺寸。

弹层通过 Radix Portal 渲染到当前 WebView 的 `body`，继承根主题变量；显式使用产品字体、字号和语义色。列表同时限制为 240px 与实际可用高度，保持无可见滚动条且可滚动。

Vite 静态导入根 Tailwind 配置，使主题和平台变体配置变更进入开发服务的重载依赖；内容扫描统一转换为绝对路径，避免根目录与 Tauri 启动目录不同导致漏扫。开发页与生产构建分别检查：运行开发服务后执行 `pnpm run check:dev`，默认检查 `http://127.0.0.1:1420`，也可追加其他开发地址。该检查确认生成的主题规则，不代替浏览器视觉验收。

选择器列表与日期右键菜单分别保留原有外观：右键菜单使用 10px 圆角、轻阴影和无边框容器，桌面菜单项高 28px、内边距 4px / 12px；触控菜单项仍至少 44px。

## 保留的视觉与交互

- 控件可见高度 28px、圆角 8px、文字 13px / 20px；开关轨道 36×20px、滑块 16px；主题选择卡片保留 66px 高度和选中描边。
- 触控仅扩大透明区域至至少 44px，按钮与下拉可见底色仍为 28px，列表项至少 44px。320px 视口保持年月导航同一行，无横向溢出。
- 自定义强调色、浅深色、邻月淡化、节气与节日语义色、今日标记、日期选中浅底、休班角标和完整黄历均沿用当前规则。
- 鼠标与触屏的悬停反馈分离；键盘保留中性细描边、方向键、Tab 和回车。下拉与菜单打开时 Esc 先关闭弹层，后续 Esc 才返回或收起日历；弹层内按键不触发外层月份快捷键。
- 标签页首次访问时挂载，之后隐藏而不销毁；格式草稿、错误提示和滚动位置可以保留。非活动页不参与布局与焦点顺序。
- 更新按钮加载时保留标签占位，显示进度且禁止重复操作，宽高不跳动。输入框保留系统输入法与原生表单提交。
- 原生文件/颜色选择、自启注册、签名更新和菜单栏时钟继续通过既有平台接口实现，不移入 Radix 或历法核心。

## 验证

本轮保存迁移前生产构建，并对照 1280px 网页、400px 月历与设置页的尺寸、颜色、字号、行高、内边距及圆角。记录的月历、详情、面板与工具栏指标一致；发现的预设卡片和按钮盒模型差异已修正后复查。

组件测试覆盖按钮提交类型、加载防重复与可访问名称、输入错误关联、开关状态、选择器值类型与禁用、标签关联及首次挂载。实际浏览器检查选择器、方向键与回车、分层 Esc、标签切换、格式草稿、输入校验、菜单栏入口保护、右键菜单和模拟更新进度。

320px 触控媒体模拟确认 28px 可见控件、44px 命中区域、44px 列表项及无横向溢出。该模拟不等同于真实触摸事件或手机 Safari 验收。

`check:mac` 在打包的 WKWebView 中增加 28px 年份控件、28px 月份切换按钮、40px 日期格的几何断言，继续验证共享核心、IPC、详情、窗口和后台启动。iOS 与最低支持系统仍按原有发布验收边界处理。
