# 1.0 前候选版体验

当前进入功能冻结与验收阶段，暂不增加新功能；阻断使用的问题单独修复并提交，通过检查后再建立新的体验基线。候选版仍为 **0.1.0**，不是正式 1.0 或公开分发版本。

## 固定基线

- 源码：`84cf758ae403abc8349c4c0443f41745f133c977`，已包含 Radix / Tailwind 迁移、控件状态与动效修复、黄历方位三列布局，以及随包分发的 MIT 主许可证。

## 日常使用验证

先退出正在运行的 Mac 开发实例，再打开固定候选应用；网页版开发服务可以保留。不要同时用不同源码构建的 Mac 正常实例做同一次验收。

1. 连续使用至少 24 小时，记录实际开始和结束时间、源码提交、系统与架构。自然跨过北京时间零点后，检查今天标记和日期更新；手动浏览的日期不应被重置。
2. 正常反复开关面板、进入设置、切月与切换显示模式，确认菜单栏时间在面板隐藏时仍刷新，偏好在退出重开后恢复。
3. 在日常锁屏、睡眠唤醒和外接显示器变化后，检查时间、窗口位置、圆角与内容高度；时区变更需单独记录。日历按北京时间，菜单栏时间按系统时区，两者不必显示同一天。
4. 开机自启需要在最终固定应用位置测试：开启后，下一次自然重新登录时应仅在菜单栏运行；关闭后再次登录不应自启。不要从临时解包目录注册，移动应用前先关闭自启。详细步骤见[开机自启](开机自启.md)。
5. 最新网页正式部署后，用真实手机 Safari 检查首屏、切月、设置、旋转与前后台恢复。现有私有预览尚未同步最新源码，不能用它签收本次基线。

当前未自动启动 24 小时驻留，也未更改系统时间、时区、启动项或登录状态。模拟跨日、浏览器尺寸和后台参数冒烟，分别只覆盖对应逻辑，不能替代以上实机操作。
