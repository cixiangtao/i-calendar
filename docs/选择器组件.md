# 选择器组件

年份、月份与 Mac 菜单栏时间格式统一使用共享 UI 导出的 `CalendarSelect`。它基于项目已有的 Ant Design Select，集中处理主题、圆角、列表、选中勾选及键盘行为；业务不再直接编写原生 `select` 或分别覆盖底层控件样式。

## 使用

```tsx
import { CalendarSelect } from '@i-calendar/ui';

<CalendarSelect
  label="月份"
  value={month}
  options={[
    { value: 11, label: '11月' },
    { value: 12, label: '12月' },
  ]}
  onChange={setMonth}
/>;
```

`value` 可以是字符串或数字，`onChange` 保留相同类型，不需要从 DOM 事件中手动转换。设置表单可传入 `id`，供外部 `label` 的 `htmlFor` 关联；`label` 属性始终提供可访问名称。

| 属性         | 作用                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| `label`      | 必填，可访问名称                                                       |
| `value`      | 必填，当前字符串或数字值                                               |
| `options`    | 必填，只读选项数组；每项包含 `value`、纯文本 `label` 及可选 `disabled` |
| `onChange`   | 必填，接收新值；持久化与业务状态由调用方负责                           |
| `id`         | 可选，表单标签关联                                                     |
| `className`  | 可选，布局宽度等场景样式，不能另起一套控件视觉                         |
| `popupWidth` | 可选，列表宽度，默认 128px；底层保证至少与控件等宽                     |
| `disabled`   | 可选，禁用整个控件                                                     |

组件仅处理受控单选，不开放搜索、多选、任意选项渲染或底层样式透传。未来有明确场景再扩展。

## 视觉与交互

- 按钮可见高度 28px、8px 圆角，文字 13px / 500 / 20px；触控下透明点击区域扩大至至少 44px。
- 弹出列表采用当前主题的面板色与边框色。选中项保持普通文字、透明底和灰色小勾，不使用强调色填充或加粗；悬停和键盘活动项使用淡灰底。普通列表项最小高度 32px，触控下至少 44px。
- 展开时触发器保持中性灰底。鼠标与触控不出现焦点描边；Tab、方向键等键盘操作显示 1px 中性细描边，不叠加底层组件默认的蓝色边框和光圈。失焦后清除焦点状态。
- 年份列表展开后滚动到当前值；列表最大内容高度 240px，保留全部真实选项 DOM 以便辅助技术访问。
- 方向键选择、回车确认；展开时 Esc 只关闭列表，关闭后再按 Esc 由日历处理返回或收起。
- 点击外部或窗口失焦关闭列表。列表属于当前 WebView，Mac 不再为它设置原生选择器的交互忙碌标记。
- 颜色沿用 `color-theme.ts` 生成的 CSS 变量和 Ant Design 主题，不进入日历核心。

浏览器已检查桌面、窄屏和触控模拟，Mac 已打包并通过真实 WKWebView 冒烟检查；没有据此宣称 iOS 模拟器或真机已验收。
