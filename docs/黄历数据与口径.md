# 黄历数据与口径

i日历 0.1.0 提供年月日干支、每日宜忌、冲煞、喜神、福神、财神以及阴阳贵神方位。计算和查询全部在 `packages/calendar-core` 内完成，UI 只展示结构化结果。本轮不含时柱、时辰宜忌、吉时或晚子时推断。

## 来源

使用锁定的 [lunar-typescript 1.8.7](https://github.com/6tail/lunar-typescript)，采用 MIT 许可。上游提供[干支 API 口径](https://6tail.cn/calendar/lunar.ganzhi.html)、[宜忌资料与流派说明](https://6tail.cn/calendar/lunar.yiji.html)、[神煞方位 API](https://6tail.cn/calendar/lunar.jishen.html)。上游作者说明宜忌数据来自对 2345 日历十多年资料的整理归纳。

黄历属于传统历法及民俗资料，各资料源和流派可能存在差异；不承诺与百度或其他黄历逐项一致。官方放假调休由另一套年度通知快照处理，黄历结果不代表法定休班安排。

## 固定规则

规则标识为 `shiri-almanac-v1`，结果中的 `rules` 和 `source` 可供客户端展示及追溯。

| 项目           | 固定口径                                   | 上游调用                     |
| -------------- | ------------------------------------------ | ---------------------------- |
| 输入           | 1901—2100 年，严格的 `YYYY-MM-DD` 公历日期 | 与核心日期校验共用           |
| 年干支         | 正月初一换年                               | `getYearInGanZhi()`          |
| 月干支         | 节交接日的零点换月，不取精确交节时刻       | `getMonthInGanZhi()`         |
| 日干支         | 北京时间零点换日                           | `getDayInGanZhi()`           |
| 每日宜忌       | 流派 1                                     | `getDayYi(1)`、`getDayJi(1)` |
| 福神方位       | 流派 1                                     | `getDayPositionFuDesc(1)`    |
| 其他方位及冲煞 | 使用同一日期的日级 API                     | `getDayPositionXiDesc()` 等  |

福神必须显式传入 1：上游默认是流派 2，2026-12-01 流派 1 为正南、流派 2 为正北。当前选择流派 1 与参考图口径一致，不能在库升级时无意切换回默认。

本 API 处理日历日期，不接收时间戳或设备时区。若调用方手中是时刻，应先用 `dateForInstant(instant, 'Asia/Shanghai')` 得到日期。年干支不以立春换年，月干支不按农历初一换月；后续若支持八字或时辰，须另行定义 API 与口径。

## 参考样例与边界

2026-12-01：农历十月廿三，丙午年、己亥月、己酉日。宜 21 项，忌“移徙、入宅、出火、入殓、安葬”；冲“(癸卯)兔”，煞东，喜神东北、福神正南、财神正北。

2026-02-04 立春当日月柱由己丑转为庚寅，年柱仍为乙巳；2026-02-17 正月初一才转为丙午年。上述分界及日期范围均有回归测试。

宜忌数组保留上游原文，包括 `['无']`。不得将“无”改写为“诸事皆宜”或删去“不宜”等内容。界面完整展示事项，长内容滚动查看，不截断成少数项目。

## 更新与复用

`getAlmanac(date)` 和 `CalendarEngine.getAlmanac(date)` 返回 `DayAlmanac` 普通对象，可序列化且调用间互不共享可变结果。无需年度黄历下载，不依赖调休覆盖；2028 等未安装调休的年份仍可查询。

更换上游版本时，核对锁文件、来源版本、完整样例和历法边界；改变分界或流派时更新规则标识与说明。Mac、iOS 和 Web 共用结果，禁止在平台或 UI 内另算一套。

## 生肖与公历星座

日期摘要中的生肖来自 `CalendarDay.lunar.zodiac`，采用同一农历年的正月初一年界：2026-02-16 仍为蛇，2026-02-17 转为马。生肖与公历年、立春分界及星座分别处理。

`CalendarDay.constellation` 使用锁定库的 `Solar.getXingZuo()`，输出补齐“座”后缀，规则见[上游 Solar 实现](https://github.com/6tail/lunar-typescript/blob/master/src/lib/Solar.ts)。采用固定公历月日区间：水瓶 1/20、双鱼 2/19、白羊 3/21、金牛 4/20、双子 5/21、巨蟹 6/22、狮子 7/23、处女 8/23、天秤 9/23、天蝎 10/24、射手 11/23、摩羯 12/22 起，至下一星座开始日前结束；摩羯区间跨公历年。

例如 2026-11-12 为“生肖 马 · 星座 天蝎座”。这属于日期级信息，未按出生地点、时刻或精确太阳位置另作推算。星座字段与原有黄历规则独立，不改变 `shiri-almanac-v1` 的含义。
