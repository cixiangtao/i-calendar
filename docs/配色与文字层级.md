# 配色与文字层级

在「设置 → 外观 → 主题」可选清爽白、暖纸色、雾灰蓝、山雾与暮紫。清爽白沿用原默认浅深配色与纯色背景，首次使用时自动选中。跟随系统、浅色和深色的选择独立于主题。

## 自定义主题

从任意内置主题打开「自定义主题」，可分别编辑浅色与深色。页面背景、卡片底色和操作强调色直接可见，其他五项位于「更多颜色」。每项均可用系统取色器，HEX 和 RGBA 共用一行输入。RGBA 可以输入 `247,250,248,0.72` 或粘贴完整的 `rgba(...)`。粘贴旧 HSL(A) 色值时会转换到当前显示格式。背景相关主色可带透明度，格式切换只改变文本表示。当前字段有未提交内容时，按 Esc 可撤回该项。

编辑草稿直接显示在当前窗口。切换浅色或深色草稿时，窗口临时跟随。点「查看月历」查看实际效果，再点「继续编辑」回到原表单和滚动位置。点「取消」恢复已应用主题。点「保存并应用」写入主题，随后窗口恢复日常明暗模式。

本地 JPG、PNG、WebP 可设为应用画布的背景图。月历、详情、设置和日期计算共用已应用的主题。卡片底色的 Alpha 为零时露出卡片下方的背景图，介于零和一之间时显示带颜色的半透明底。单独的按钮、输入和弹层沿用各自的控件色。图片强度与裁切使用同一款滑动条即时预览，强度为零时使用纯色画布。

主题导出为 `.zip`，旧版 `.icaltheme` 和 JSON 也可导入。导入先校验并显示预览，再选择应用，遇到同标识的自定义主题时可替换或另存。旧版自定义配色迁入「我的主题」，旧版停用的配色也可以再次选用。详见[主题模型](主题模型.md)。

## 文字层级

主要文字使用中性炭灰或明亮的浅灰，减少蓝灰色调。公历数字、日期标题、干支值、宜忌正文与方位值使用主要文字；星期栏、详情标签、农历和说明根据阅读角色分别配色。相邻月份通过弱化文字和较轻字重退后，仍保持小字可读。

| 默认清爽白 | 浅色      | 深色      | 用途                     |
| ---------- | --------- | --------- | ------------------------ |
| 主要文字   | `#303030` | `#f3f3f3` | 公历、标题、干支与正文   |
| 星期文字   | `#4f4f4f` | `#d4d4d6` | 星期栏的普通日期         |
| 标签文字   | `#616161` | `#c7c8c9` | 生肖、星座与方位标签     |
| 农历文字   | `#6e6e6e` | `#a9aaae` | 月历与详情中的普通农历   |
| 说明文字   | `#6e6e6e` | `#9fa1a5` | 设置帮助与官网说明       |
| 月外文字   | `#a5a5a5` | `#71747a` | 相邻月份的普通日期及农历 |
| 面板背景   | `#ffffff` | `#222630` | 日历、详情和设置面板     |

月外文字采用独立的 `--outside-ink`，比本月普通农历再淡一档；月外周末、节气和节日也向面板底色弱化。只调整文字颜色，不给整格设置透明度，休班角标、假期底色及选中状态保持完整。颜色按实际背景派生，浅深色和各主题共用同一层级规则。

## 强调色的用途

操作、选中日期数字、今日实底、选中底色和主要按钮采用同一强调色族。周末与休假共用醒目的红色体系，节气采用清爽绿，补班黄与节日紫保持独立语义，也继续配合文字与角标表达。语义主色由 `theme-package.ts` 提供，实际文字及其轻染底色统一由 `color-theme.ts` 派生，适配各主题及浅深色。

今天的公历和第二行文字均使用白色，底色复用与白字对比度至少 4.5:1 的主题强调色。选中其他日期时，日期格使用主题色浅底，公历数字加粗并使用强调色、普通农历使用选中墨色，节气与节日继续使用绿色和紫色，保证在选中底色上可辨。相邻月份的周末、节气、节日使用弱化后的语义色；普通农历不会因放假统一改成红色。详情中同一类信息沿用月历的颜色，标签与数值分层。

保存原始颜色，派生时将卡片色与页面底色合成，再将文字向黑或白混合。当前月与详情的普通文字、强调色和语义色按合成底、控件、假期及选中色计算，目标为 4.5:1。有背景图时，透明区域的实际对比度随图片变化。常规模式的月外上下文文字单独弱化，对比度下限为 2.2:1，增加对比度模式下恢复至 7:1。今日实底和主要按钮采用白字，单独派生可读底色。增加对比度模式将次级文字、弱化文字和强调色文字目标提升至 7:1。

例如浅色下选择纯黄，按钮文字会使用较深的黄色派生色，选择底色保持轻染黄色；深色下选择纯黑，文字使用更亮的中性派生色，今日实底和主要按钮仍可用黑底白字。设置里的色块和色值始终显示用户原始选色。

## 实现与验证

主色与主题包契约集中在 `packages/calendar-ui/src/theme-package.ts`，派生规则位于 `color-theme.ts`，均不依赖平台或网络，不进入 `calendar-core`。`scripts/theme-css.ts` 在构建时调用同一派生器生成首帧浅深色及增加对比度样式，不手写派生色回退表。Tailwind 与少量全局 CSS 共用计算结果；新增控件悬停与按下底色，次要文字和操作文字同时对这些底色校验对比度，占位文字使用同一次要文字色。开关开启与关闭态分别派生悬停和按下颜色，校验白色滑块对轨道的对比度不低于 4.5:1。旧版预设、强调色与高级配色通过只读迁移转换为主题模型，下一次正常保存写入主题库。

历史验证覆盖当时的三种预设、浅深色、增加对比度偏好以及黑、白、红、绿、蓝、黄和灰等强调色。浏览器已验证预设切换、刷新恢复、恢复默认、320px 设置页和 Mac 内容尺寸；原生应用通过真实 WKWebView 冒烟检查。尚未完成 iOS 真机及 Mac 系统颜色面板的完整操作验收。
