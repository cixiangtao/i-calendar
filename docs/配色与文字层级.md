# 配色与文字层级

在设置的“配色”中选择清爽白、暖纸色或雾灰蓝，也可以点击强调色色块使用系统颜色选择器。修改立即生效并保存在本地；“恢复默认”仅清除自定义强调色。切换预设会恢复该预设的默认强调色，外观的跟随系统/浅色/深色选择保持独立。

## 文字层级

主要文字使用更深的墨色或明亮的浅色，覆盖日期、干支、宜忌正文与方位值；农历、方位标签、设置说明使用次级灰，相邻月日期使用弱化灰。弱化不依赖透明度，保持正常字号下的可读性。

| 默认清爽白 | 浅色      | 深色      |
| ---------- | --------- | --------- |
| 主要文字   | `#171b24` | `#f6f7fb` |
| 次要文字   | `#5b6575` | `#acb4c3` |
| 弱化文字   | `#6e7787` | `#929dac` |
| 面板背景   | `#ffffff` | `#222630` |

## 强调色的用途

操作、选中描边、今日圆点、选中底色和日期叶片采用同一强调色族。休假红、节气绿、补班黄和节日紫保持原有语义，也继续配合文字与角标表达。

保存原始颜色，显示时按当前背景向黑或白混合，找到满足对比度的派生色。普通文字及强调色文字与对应背景至少达到 4.5:1；日期叶片采用白字，单独派生可读底色。增加对比度模式将次级文字、弱化文字和强调色文字目标提升至 7:1。

例如浅色下选择纯黄，按钮文字会使用较深的黄色派生色，选择底色保持轻染黄色；深色下选择纯黑，文字使用更亮的中性派生色，日期叶片仍可用黑底白字。设置里的色块和色值始终显示用户原始选色。

## 实现与验证

规则集中在 `packages/calendar-ui/src/color-theme.ts`，不依赖平台或网络，不进入 `calendar-core`。CSS 与 Ant Design 共用计算结果。默认旧设置补齐 `colorTheme: 'clear'` 和 `accentColor: null`，保持现有明暗外观与周起始日；新字段只接受预设标识或完整 RGB 十六进制值。

测试覆盖三种预设、浅深色、增加对比度偏好以及黑、白、红、绿、蓝、黄和灰等强调色。浏览器已验证预设切换、刷新恢复、恢复默认、320px 设置页和 Mac 内容尺寸；原生应用通过真实 WKWebView 冒烟检查。尚未完成 iOS 真机及 Mac 系统颜色面板的完整操作验收。
