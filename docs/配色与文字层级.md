# 配色与文字层级

在设置的“配色”中选择清爽白、暖纸色或雾灰蓝，也可以点击强调色色块使用系统颜色选择器。修改立即生效并保存在本地；“恢复默认”仅清除自定义强调色。切换预设会恢复该预设的默认强调色，外观的跟随系统/浅色/深色选择保持独立。

## 高级配色

在“设置 → 常规 → 配色”展开“高级配色”。只编辑八个主色：页面背景、卡片背景、主要文字、操作强调色，以及休假/警告、节气/工作日、补班/提醒和节日四个语义主色。浅色与深色分别保存，关闭后保留选色。

系统自动生成次要、农历、说明与星期文字，控件悬停和按下、选中浅底、边框、月外日期、日期叶片与开关颜色；不提供派生色的独立编辑入口。主色保存原始值，实际显示的文字按背景校正对比度，避免主色组合导致不可读。无法同时满足的背景对比要求会提示，不阻止保存。

每项支持系统取色器与完整 `#RRGGBB` 输入；文本在失焦或 Enter 时提交，非法色值不写入，Esc 撤回草稿。支持逐项恢复、恢复当前外观和清除两套主色；基础主题与强调色保持独立。编辑区使用基础主题，恢复入口保持可读；品牌图标保持原色。

1.0.3 的完整配色载入时保留八个主色，其他已知派生色通过格式校验后不再应用，后续保存只写主色；未知键与非法色值仍拒绝。原文件在加载时不会主动改写。

内置主题和未来主题包共用八主色数据契约，格式与规则独立版本化。详见[主题模型](主题模型.md)。

## 文字层级

主要文字使用中性炭灰或明亮的浅灰，减少蓝灰色调。公历数字、日期标题、干支值、宜忌正文与方位值使用主要文字；星期栏、详情标签、农历和说明根据阅读角色分别配色。相邻月份通过弱化文字和较轻字重退后，仍保持小字可读。

| 默认清爽白 | 浅色      | 深色      | 用途                     |
| ---------- | --------- | --------- | ------------------------ |
| 主要文字   | `#303030` | `#f3f3f3` | 公历、标题、干支与正文   |
| 星期文字   | `#4f4f4f` | `#d4d4d6` | 星期栏的普通日期         |
| 标签文字   | `#616161` | `#c7c8c9` | 生肖、星座与方位标签     |
| 农历文字   | `#6e6e6e` | `#a9aaae` | 月历与详情中的普通农历   |
| 说明文字   | `#6e6e6e` | `#9fa1a5` | 设置帮助与官网说明       |
| 月外文字   | `#a5a5a5` | `#71747a` | 相邻月份的普通日期及农历 |
| 面板背景   | `#ffffff` | `#222630` | 日历、详情和设置面板     |

月外文字采用独立的 `--outside-ink`，比本月普通农历再淡一档；月外周末、节气和节日也向面板底色弱化。只调整文字颜色，不给整格设置透明度，休班角标、假期底色及选中状态保持完整。颜色按实际背景派生，浅深色和三套预设共用同一层级规则。

## 强调色的用途

操作、选中描边、今日实底、选中底色和日期叶片采用同一强调色族。周末与休假共用醒目的红色体系，节气采用清爽绿，补班黄与节日紫保持独立语义，也继续配合文字与角标表达。语义主色由 `theme-package.ts` 提供，实际文字及其轻染底色统一由 `color-theme.ts` 派生，适配三套预设及浅深色。

今天的公历和第二行文字均使用白色，底色复用与白字对比度至少 4.5:1 的主题强调色。选中其他日期时，公历使用强调色、普通农历使用选中墨色，节气与节日继续使用绿色和紫色，保证在选中底色上可辨。相邻月份的周末、节气、节日使用弱化后的语义色；普通农历不会因放假统一改成红色。详情中同一类信息沿用月历的颜色，标签与数值分层。

保存原始颜色，显示时按当前背景向黑或白混合，找到满足对比度的派生色。当前月与详情的普通文字、强调色和语义色文字与对应背景至少达到 4.5:1，覆盖普通面板、控件底色、假期及选中背景。根据用户明确要求，常规模式的月外上下文文字单独弱化，对比度下限为 2.2:1；增加对比度模式下恢复至 7:1。日期叶片采用白字，单独派生可读底色。增加对比度模式将次级文字、弱化文字和强调色文字目标提升至 7:1。

例如浅色下选择纯黄，按钮文字会使用较深的黄色派生色，选择底色保持轻染黄色；深色下选择纯黑，文字使用更亮的中性派生色，日期叶片仍可用黑底白字。设置里的色块和色值始终显示用户原始选色。

## 实现与验证

主色与主题包契约集中在 `packages/calendar-ui/src/theme-package.ts`，派生规则位于 `color-theme.ts`，均不依赖平台或网络，不进入 `calendar-core`。`scripts/theme-css.ts` 在构建时调用同一派生器生成首帧浅深色及增加对比度样式，不手写派生色回退表。Tailwind 与少量全局 CSS 共用计算结果；新增控件悬停与按下底色，次要文字和操作文字同时对这些底色校验对比度，占位文字使用同一次要文字色。开关开启与关闭态分别派生悬停和按下颜色，校验白色滑块对轨道的对比度不低于 4.5:1。默认旧设置补齐 `colorTheme: 'clear'` 和 `accentColor: null`，保持现有明暗外观与周起始日；新字段只接受预设标识或完整 RGB 十六进制值。`customColors` 包含 `enabled`、`light` 和 `dark`，浅深色偏好仅保存八个主色，CSS 角色名只作为旧存储适配；主题包使用独立主色名称；未知角色、任意 CSS 表达式、非布尔开关与非完整色值均拒绝载入，解析时复制对象以隔离外部修改。日期叶片文字/圆孔与开关滑块使用生成器输出，组件不单独定义色值。

测试覆盖三种预设、浅深色、增加对比度偏好以及黑、白、红、绿、蓝、黄和灰等强调色。浏览器已验证预设切换、刷新恢复、恢复默认、320px 设置页和 Mac 内容尺寸；原生应用通过真实 WKWebView 冒烟检查。尚未完成 iOS 真机及 Mac 系统颜色面板的完整操作验收。
