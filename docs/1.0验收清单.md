# 1.0 验收清单

2026-11-13 更新。首个 1.0 的交付范围已由用户确定为 **Mac＋网页版**，iOS 在后续版本交付。当前版本仍为 **0.1.0**，已固定本地体验基线，进入功能冻结和实机验收，尚未达到正式发布条件。

## 当前体验基线

- 源码提交：`84cf758ae403abc8349c4c0443f41745f133c977`。
- 固定目录：`outputs/candidate-0.1.0-84cf758/`，包含独立 Mac 应用、ZIP、源码归档、网页快照、`manifest.json` 和 `SHA256SUMS.txt`；后续普通构建不会覆盖它。
- 本轮从 ZIP 在新的临时目录解包，重新验证签名、版本、arm64 架构和随附许可证，并执行普通 / 后台两种真实 WKWebView 冒烟，均通过；网页资源引用存在，无源码映射、Vite 开发入口或本机绝对路径。
- 已复核根包、两个共享包、Tauri、Cargo 与实际应用版本均为 0.1.0。本轮重新构建包含 MIT 的产物，来源业务代码与许可证配置均已提交并固定，之后仅整理验收文档。
- 日常验证步骤与记录方式见[候选版体验](候选版体验.md)。此前模拟验证与短时冒烟继续有效，但不替代下方待完成的实机项目。

## 实机验证与发布决策

Mac 开机自启已接入，发布前需在最终应用位置实测“开启 → 重新登录后仅菜单栏运行 → 关闭后不再自启”；隔离的后台启动冒烟不能替代真实登录验收，详见[开机自启](开机自启.md)。

2026-11-13 补充：已接入 Mac 自动更新流程与签名打包、清单工具，默认自动检查，确认后下载并安装。开发及隔离冒烟不联网请求更新；自动检查、重试、版本签名与 UI 模拟已覆盖，详见[自动更新](自动更新.md)。正式源、长期密钥、Apple 签名与真实安装位置的升级重启验收仍需在发布前完成。
