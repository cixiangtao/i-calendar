# i日历 1.0.3

本次增加全量高级配色，并优化 Mac 弹窗关闭后的页面恢复与退出入口。

## 更新内容

- 在“设置 → 常规 → 配色”展开“高级配色”，可自定义背景、文字、控件、选中状态、语义颜色、月外日期、日期叶片和开关，共 37 个颜色角色。
- 浅色与深色分别保存，支持系统取色、完整十六进制色值输入与即时预览；关闭高级配色保留选色，未修改项继续跟随主题。
- 提供单项恢复、恢复当前外观与全部恢复；提示常用组合的低对比度，高级编辑区保持可读，品牌图标保留原色。旧设置默认关闭高级配色。
- Mac 弹窗滑出并真正隐藏后恢复日历页，下次打开直接查日历；保留已选日期和偏好。退场途中再次打开时保留当前页面，避免切换闪动。
- “退出i日历”固定在设置面板最下方，各标签页均可访问；使用红色警告及悬停/按下样式，下载与安装更新时仍保持禁用。
- 补足说明文字在页面底色上的对比度，以及增加对比度模式下主要文字在控件按下背景上的对比度。

## 下载与更新

- Mac 安装包仅提供 Apple 芯片 arm64，配置最低 macOS 13，当前验证环境为 arm64 / macOS 15.7。Intel 与 iOS 安装包尚未提供。
- 已安装正式版可在“设置 → 关于”检查更新，确认后下载、验签并安装；也可下载 ZIP，退出旧版后手动替换固定位置的 `i日历.app`。本地预览包请手动安装正式版。
- **Mac 包仍为 ad-hoc 本地签名，未通过 Apple Developer ID 签名或 Apple 公证。** 请从官方 Release 下载并核对 `SHA256SUMS.txt`，不要关闭系统全局安全保护。
- 首次安装请选择 `i-calendar-1.0.3-mac-arm64.zip`；`.app.tar.gz`、`.sig` 与 `latest.json` 用于应用更新。更新公钥与正式更新地址沿用原配置。

## 验证范围

代码回归覆盖旧偏好兼容、非法色值与未知角色拦截、全角色覆盖、浅深色隔离、关闭保留、持久化及对比度提示；浏览器预览覆盖 400px 与 320px 的编辑、刷新、恢复与布局。Mac 页面恢复已通过真实 AppKit / WKWebView 的普通及后台启动、退出动画、快速重开与内容高度检查。

原生系统取色面板的完整操作、真实安装位置的跨版本升级重启、最低系统、多屏矩阵、系统减少动态效果设置与 iOS 真机仍未完整验收；不把工具验签和隔离冒烟等同于这些项目的完整实测。
