# i日历 1.0.4

本次将高级配色收敛到八个主色，统一内部派生规则，为后续主题包与社区扩展准备数据基础。

## 更新内容

- 高级配色只编辑页面背景、卡片背景、主要文字、操作强调色，以及红、绿、黄、紫四个语义主色。浅深色仍分别保存，支持即时预览、对比度提示和恢复。
- 次要文字、农历、说明、边框、悬停、按下、浅底、月外日期、日期叶片与开关配色均由主色生成；默认主题也遵循相同规则，文字按实际背景校正对比度。
- CSS 首帧样式和运行时切换使用同一派生器，移除单独维护的派生色回退表，保留品牌图标原色。
- 兼容 1.0.3 完整配色：载入时保留八个主色，其他已知派生色重新生成；下一次正常保存只写主色，载入不会主动改写原文件。
- 内置主题采用版本化的主题包数据契约，包含标识、名称、版本、作者及浅深色主色；格式版本与派生规则版本独立。主题文件导入/导出界面、远程安装和社区服务尚未提供。
- 发布工具直接使用创建草稿接口的响应，避免依赖紧接创建后的列表查询；正式附件、更新清单与官网仍由唯一 GitHub Actions 流程发布。

## 下载与更新

- Mac 包仅提供 Apple 芯片 arm64，配置最低 macOS 13，当前验证环境为 arm64 / macOS 15.7；Intel 与 iOS 安装包尚未提供。
- 已安装正式版可在“设置 → 关于”检查更新，确认后下载、验签并安装；也可下载 `i-calendar-1.0.4-mac-arm64.zip`，退出旧版后替换固定位置的 `i日历.app`。本地预览包请手动安装正式版。
- **Mac 包仍为 ad-hoc 本地签名，未通过 Apple Developer ID 签名或 Apple 公证。** 请从官方 Release 下载并核对 `SHA256SUMS.txt`，不要关闭系统全局安全保护。
- `.app.tar.gz`、`.sig` 与 `latest.json` 用于自动更新，延续原公钥与正式更新地址。

## 验证范围

自动测试覆盖主色派生联动、旧偏好迁移与保存、主题包校验及 JSON 往返、首帧/运行时一致性；浏览器预览覆盖 400px 与 320px 的主色联动、输入校验、刷新恢复和浅深色隔离。Mac 继续验证真实窗口的进出场、快速重开、页面恢复、内容高度和普通/后台启动。

原生系统取色面板完整操作、真实安装位置的跨版本安装重启、最低系统、多屏矩阵、系统减少动态效果设置与 iOS 真机仍未完整验收，不把工具验签或隔离冒烟等同于这些项目的完整实测。
