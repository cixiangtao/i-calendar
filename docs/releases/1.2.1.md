# i日历 1.2.1

完善 Mac 应用的更新入口与安装按钮配色，让发现的新版本更容易在日历首页找到。

## 更新体验

- “下载并安装”改为跟随当前主题的实心主操作配色，适配浅色、深色和自定义强调色，保留悬停、按下及禁用反馈。
- 检测到新版本后，日历首页底部显示“更新”按钮，点击进入“关于”查看版本说明，再决定是否下载并安装。选择“稍后”隐藏提醒后，底部入口仍然保留。
- 下载和安装期间，底部入口分别显示“下载中”和“安装中”，可进入关于页查看进度；失败后保留重试入口，确认已是最新版本后移除。
- 保留既有默认自动检查：启动、恢复焦点及每小时轮询提供检查机会，同一进程内按 24 小时间隔限频。关闭自动检查后仍可手动检查；检测到新版不会自动下载或安装。

## 下载与更新

- Mac 提供 Apple 芯片 arm64 包，配置最低 macOS 13；Intel 与 iOS 安装包尚未提供。
- **Mac 仍采用 ad-hoc 本地签名，未通过 Apple Developer ID 签名或 Apple 公证。** 请从官方 Release 下载并核对 `SHA256SUMS.txt`。
- 已安装用户可在“设置 → 关于”检查更新，或下载 `i-calendar-1.2.1-mac-arm64.zip` 后退出旧版并替换固定位置的应用。

## 验证范围

执行代码、格式、类型、共享测试与生产构建，并验证 Mac 原生包。更新界面使用隔离模拟覆盖自动发现、稍后处理、底部跳转与返回焦点、主题配色、下载中状态、失败重试、手动检查和无更新状态；模拟不会安装或重启应用。正式包及更新源由统一流水线构建和发布，并独立核对公开产物。

长期驻留、真实重新登录、最低系统、多屏矩阵、完整跨版本安装重启、手机 Safari 与 iOS 真机仍未完整验收。
