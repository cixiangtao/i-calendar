# i日历 1.3.0

新增日出、日落与白昼时长，支持国内地点选择和自动定位。

## 日出日落

- 在“设置 → 常规 → 日出日落”启用当前位置，或搜索国内城市及部分区县；日期详情随所选日期显示日出、日落与白昼时长，统一采用北京时间。
- 自动定位直接使用实际经纬度计算，不将整个城市归为市中心。Mac 系统能提供时显示区县或道路；显示实际定位精度，较粗定位给出提示。Web 使用浏览器定位，并以离线附近地名作标签。
- 内置 1,772 个国内地点参考点，手动模式明确标注参考值。日照计算可离线运行；定位和系统地名解析可能需要网络，地点数据不是完整行政区划。
- 定位默认关闭；启用后只在前台按需刷新，不持续追踪，不保存自动定位坐标和轨迹。拒绝、超时或失败后可重试、手动选择或关闭，切换地点时取消旧请求。
- 地点列表按需加载，加载失败局部回退；手机结果行的触控区域互不重叠，沿用主题和紧凑视觉。

日照基于 SunCalc 2.1.1 的理想地平线估算，不计山体、建筑及天气遮挡，定位精度以系统结果为准，不能承诺始终达到街道级。

## 下载与更新

- Mac 提供 Apple 芯片 arm64 包，最低配置为 macOS 13；Intel 与 iOS 安装包尚未提供。
- **Mac 仍为 ad-hoc 本地签名，未通过 Apple Developer ID 签名或 Apple 公证。** 请从官方 Release 下载并核对 `SHA256SUMS.txt`。
- 已安装用户可在“设置 → 关于”检查更新，或下载 `i-calendar-1.3.0-mac-arm64.zip` 后退出旧版并替换固定位置的应用。
