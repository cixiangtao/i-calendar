# i日历 2.3.0

这一版新增四款图片背景主题。点开任意日期，也能直接看见它离今天还有多少天，或已经过去了多少天。

## 四款新主题

- 海盐蓝、竹影、晚霞和樱坂电车各有浅色和深色配色，半透明卡片下能看见背景图。
- 在「设置 → 外观 → 主题」中切换。图片随应用提供，Mac 版离线也能使用；导出 ZIP 主题包时会一并保存图片。

## 日期与设置

- 日期详情会显示「还有 N 天」或「N 天前」，按北京时间的公历自然日计算。选中今天时省略提示。
- 日期计算移到设置页底部，Mac 也可从菜单栏图标的右键菜单打开。使用日期间隔、日期推算和工作日统计后，仍可从结果返回月历。
- 「关于」页新增官网入口。

## 下载和更新

已有版本可在「设置 → 关于」检查更新。Mac 安装包适用于 Apple 芯片（arm64）和 macOS 13 或更新版本。应用采用 **ad-hoc 本地签名，尚未通过 Apple 公证**。
