# i日历 1.1.1

本次进一步调整官网视觉，加入更明确的未来感光轨和空间层次，首屏继续直接使用日历。

## 更新内容

- 官网加入蓝、紫、绿主题光场与轨道；指针移动产生轻微视差，日期选择改变视觉相位。光轨只作视觉表达，不表示真实天体位置。
- 新增暂停与播放光轨入口，系统减少动态效果时保持静态；页面隐藏或光轨区域离开视口时停止持续绘制，限制帧率与画布分辨率。
- 调整首屏标题、月份和日期排版，网页版日期详情用大数字替代纸页造型，保留原有五色含义和共享控件尺寸。
- 阅读区域使用不透明主题底色，保证动态光效不干扰农历与正文阅读；浅深色、手机触控、键盘操作及现有日历能力继续可用。
- Mac 菜单栏与 iOS 不展示网页光场，继续沿用共享日历与平台行为。

## 下载与更新

- Mac 包仅提供 Apple 芯片 arm64，配置最低 macOS 13；Intel 与 iOS 安装包尚未提供。
- **Mac 包仍为 ad-hoc 本地签名，未通过 Apple Developer ID 签名或 Apple 公证。** 请从官方 Release 下载并核对 `SHA256SUMS.txt`，不要关闭系统全局安全保护。
- 已安装用户可在“设置 → 关于”检查更新，或下载 `i-calendar-1.1.1-mac-arm64.zip` 后退出旧版并替换固定位置的应用。

## 验证范围

代码检查、类型检查、共享测试与 ESM/网页构建；浏览器验证光轨播放、暂停、减少动态效果、手机触控与日历切月，独立审查浅深色和宽窄屏可读性。正式发布通过统一流水线执行 Mac 构建、签名更新包与原生冒烟。

长期驻留、真实登录、最低系统、完整跨版本安装重启、多屏矩阵与 iOS 真机尚未完整验收，不把本轮隔离检查等同于这些项目的完整实测。
