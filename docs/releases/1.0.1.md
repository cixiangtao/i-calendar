# i日历 1.0.1

本次完善 Mac 菜单栏弹层的定位与进出场动效，日历数据和网页版视觉保持原有体验。

## 更新内容

- 弹层停靠菜单栏所在屏幕的右上方，距工作区顶部与右侧各 8px，避开菜单栏与 Dock。
- 打开时从屏幕右侧以 280ms 减速滑入，收起时以 180ms 向右滑出，动画结束后才隐藏窗口。
- 退场中再次点击可从当前位置转回打开；重复收起不重播，过期完成回调及失焦请求不会误关新打开的弹层。
- 保留内容高度适配、20px 原生圆角和系统阴影；系统开启“减少动态效果”时使用 120ms 淡入与 100ms 淡出。

## 下载与更新

- Mac 安装包仅提供 Apple 芯片 arm64，配置最低 macOS 13，当前验证环境为 arm64 / macOS 15.7。Intel 与 iOS 安装包尚未提供。
- 1.0.0 正式版可通过“设置 → 关于”检查更新，确认后下载、验签并安装；也可下载 ZIP，退出旧版后手动替换固定位置的 `i日历.app`。本地预览包请手动安装正式版。
- **Mac 包仍为 ad-hoc 本地签名，未通过 Apple Developer ID 签名或 Apple 公证。** 首次打开可能出现系统提示，请从官方 Release 下载并核对 `SHA256SUMS.txt`，不要关闭系统全局安全保护。
- `.app.tar.gz`、`.sig` 与 `latest.json` 用于应用更新；首次安装请选择 `i-calendar-1.0.1-mac-arm64.zip`。

## 验证范围

全量检查、Rust 回归、真实 AppKit 进出场轨迹、快速打断重开、结束后隐藏、尺寸切换及普通 / 后台 WKWebView 冒烟已覆盖。系统减少动态效果开关、多屏矩阵、最低系统与真实安装位置的跨版本安装重启仍未完整实测，不将签名工具验证等同于完整升级验收。
