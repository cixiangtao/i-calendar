# i日历 1.3.8

「设置 → 外观」新增完整的主题编辑和分享体验。默认仍是原来的清爽白浅深配色，采用纯色背景。

## 主题

- 新增「山雾」与「暮紫」两个可选主题。可从内置主题创建自己的主题，分别编辑浅色与深色，并实时查看日期预览。
- 颜色可输入 HEX、RGB(A) 和 HSL(A)，页面背景与卡片底色支持透明度。可选取本地 JPG、PNG 或 WebP 作为背景，调整裁切位置和强度。
- 使用 `.icaltheme` 文件分享配色、背景图和裁切设置。导入先预览再应用，同一个自定义主题可替换或另存副本。
- 已有自定义配色会自动迁入「我的主题」。
