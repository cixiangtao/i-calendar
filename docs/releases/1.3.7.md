# i日历 1.3.7

设置新增「外观」和「日出日落」分类，日期计算移到月历上方。

## Mac 首次打开

从本页下载安装包，解压并将 i日历拖到「应用程序」，然后双击打开。若 macOS 提示无法验证开发者，请先确认安装包来自本项目官方 Release，再前往「系统设置 → 隐私与安全性」，为 i日历选择「仍要打开」。

## 设置与日期计算

- 「常规」保留每周起始日、农历详情和 Mac 开机自启。「外观」集中管理明暗模式、主题和高级配色，「日出日落」集中管理定位与手动地点。
- 月历上方「今天」旁的计算器图标可以直接打开日期计算，以当前选中的日期开始。关闭农历详情时也能使用。
