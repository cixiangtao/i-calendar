# i日历 1.2.0

新增轻量日期计算工具。点击日历底部的“日期计算”，即可计算日期间隔、向前或向后推算日期，以及按全国放假调休统计工作日；Mac 与网页版共用同一界面和规则。

## 新增功能

- **日期间隔**：输入两个公历日期查看相隔天数，结束日期在前时明确说明方向。
- **前后推算**：输入正数或负数自然日，直接得到目标日期，支持跨月、跨年和闰年。
- **工作日统计**：扣除已收录的休假与普通周末、计入补班；默认不计起始日、计入结束日，可开启“计入起始日”。缺少参与计算日期的调休安排时，提示缺失年份，不显示推测的工作日数量。
- **查看结果**：计算完成后可跳回月历选中对应日期；返回或按 Esc 保留原选中日期。输入格式、整数天数和 1901—2100 年范围均有校验，计算草稿不写入偏好。

## 下载与更新

- Mac 包提供 Apple 芯片 arm64，配置最低 macOS 13；Intel 与 iOS 安装包尚未提供。
- **Mac 包仍为 ad-hoc 本地签名，未通过 Apple Developer ID 签名或 Apple 公证。** 请从官方 Release 下载并核对 `SHA256SUMS.txt`。
- 已安装用户可在“设置 → 关于”检查更新，或下载 `i-calendar-1.2.0-mac-arm64.zip` 后退出旧版并替换固定位置的应用。

## 验证范围

本轮覆盖日期计算边界、调休缺失、补班、跨年、闰年、视图往返与草稿隔离测试，执行类型检查、代码及格式检查、共享核心和网页构建。浏览器检查桌面与手机宽度、浅深色、错误提示、键盘焦点与结果跳转；Mac 隔离冒烟增加真实 WKWebView 输入及点击验证，并沿用原生窗口生命周期检查。正式产物仍由统一发布流水线构建、验签和发布。
