# i日历 1.2.2

更新说明支持 Markdown 排版，在 Mac 应用内直接阅读标题、列表、强调、代码和链接。

## 更新说明

- 展开“更新说明”后按需加载渲染模块，收起时不请求 Markdown 分包；再次展开复用已加载模块。
- 采用与日历一致的浅深色主题和紧凑字号，长段落、文件名可换行，长代码块和表格在自身范围滚动。
- 说明链接通过系统浏览器打开，仅接受无凭据的 HTTPS 地址；原始 HTML 按文本显示，图片保留描述，不发起远程图片请求。
- 排版模块加载或渲染失败时，保留原始说明与更新操作，不影响日历、下载或安装。

## 下载与更新

- Mac 提供 Apple 芯片 arm64 包，配置最低 macOS 13；Intel 与 iOS 安装包尚未提供。
- **Mac 仍为 ad-hoc 本地签名，未通过 Apple Developer ID 签名或 Apple 公证。** 请从官方 Release 下载并核对 `SHA256SUMS.txt`。
- 已安装用户可在“设置 → 关于”检查更新，或下载 `i-calendar-1.2.2-mac-arm64.zip` 后退出旧版并替换固定位置的应用。
