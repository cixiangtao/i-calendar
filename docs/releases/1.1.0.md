# i日历 1.1.0

本次重新设计网页版官网，以更现代的时间仪表台组织日历、日期详情与 Mac 下载，首屏仍可直接查日期。

## 更新内容

- 新增轻量品牌导航，宽屏将月历与详情收纳进同一框架，以分隔线、留白和五色图例建立清晰层级；手机按月历、详情与图例顺序阅读。
- 加入日历首次就绪的边界过渡、按方向切月的短促反馈与下载箭头悬停反馈；开启系统“减少动态效果”时省略这些动画，重复切月会取消旧动画。
- 下载、版本说明、数据来源与开源信息集中在日历下方，官网下载地址随当前版本同步。
- 继续复用共享日历核心、控制器、主题与基础控件；浅深色、键盘选日、设置入口与调休未知提示保持可用。

## 下载与更新

- Mac 包仅提供 Apple 芯片 arm64，配置最低 macOS 13；Intel 与 iOS 安装包尚未提供。
- **Mac 包仍为 ad-hoc 本地签名，未通过 Apple Developer ID 签名或 Apple 公证。** 请从官方 Release 下载并核对 `SHA256SUMS.txt`，不要关闭系统全局安全保护。
- 已安装用户可在“设置 → 关于”检查更新，或下载 `i-calendar-1.1.0-mac-arm64.zip` 后退出旧版并替换固定位置的应用。

## 验证范围

本轮执行代码检查、类型检查、共享测试与 ESM/网页构建；浏览器检查覆盖桌面、窄屏、浅深色、切月、今天、设置及减少动态效果。正式发布继续通过统一流水线构建并验证 Mac 安装与更新包。

长期驻留、真实登录项、最低系统、完整跨版本安装重启、多屏矩阵与 iOS 真机尚未完整验收，不把本轮布局检查或隔离冒烟等同于这些项目的完整实测。
