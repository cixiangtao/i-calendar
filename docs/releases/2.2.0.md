# i日历 2.2.0

编辑主题时，当前窗口会实时显示配色、透明度和背景图。

## 自定义主题

- 点「查看月历」即可在真实月历中查看日期和黄历详情的显示效果。点「继续编辑」返回原有表单和滚动位置。
- 编辑浅色或深色草稿时，窗口临时切换到对应模式。「取消」恢复原主题，「保存并应用」写入草稿并恢复日常明暗模式。
- 修正 Mac 切换主题时卡片可能残留旧底色的问题。卡片按设定的透明度绘制。将 Alpha 设为零，可以从月历、日期详情、设置和日期计算的卡片下方看到背景图。

## 主题包

- 默认导出为 `.zip`，可以直接用系统解压工具打开。本地图片随包保存，在线图片保留 HTTPS 链接。
- 旧版 `.icaltheme` 和 JSON 主题包仍可导入。
