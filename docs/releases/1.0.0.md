# i日历 1.0.0

首个正式版本，提供免费的 Mac 菜单栏日历与网页版，无广告、无需登录。iOS 将在后续版本提供。

## 功能

- 公历、农历、生肖、星座、节气、传统节日及中国大陆放假 / 补班，内置 2025—2027 年调休；未收录年份明确提示。
- 完整展示年月日干支、宜忌、冲煞和主要方位；固定数据口径与来源可追溯。
- 菜单栏图标与时间显示、时间格式设置、开机自启、主题预设与自定义强调色。
- 圆角悬浮面板、紧凑月历、宽屏双栏、键盘操作和统一的 Radix / Tailwind 控件。
- 内置正式更新源与公钥，自动检查新版本，用户确认后才下载、验签和安装。

## 下载与安装

本次提供 **Apple 芯片 arm64** 的 Mac ZIP，配置最低 macOS 13，已在 arm64 / macOS 15.7 验证。Intel 与 iOS 安装包不在本次发布范围。

下载 ZIP 后解压，将 `i日历.app` 放到固定位置（建议“应用程序”），退出原开发实例或旧版后打开。0.1.0 预览没有正式更新源，需要手动安装本版；1.0.0 起的更新使用随附公钥验证。移动应用位置前先关闭开机自启，移动后再开启。

**当前 Mac 包采用 ad-hoc 本地签名，尚无 Developer ID，也未通过 Apple 公证。** macOS 可能提示无法验证开发者。请从本仓库 Release 下载并核对 `SHA256SUMS.txt`；是否允许打开由你按系统提示决定，不需要关闭系统全局安全保护。
