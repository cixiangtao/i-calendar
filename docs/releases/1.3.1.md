# i日历 1.3.1

精简首页信息，并优化自动定位的权限申请和恢复路径。

## 首页更紧凑

- 移除底部重复的更新按钮，保留自动检查、新版提醒及“设置 → 关于”的查看与下载操作；“下载并安装”继续使用主题色。
- 日出、日落与白昼合并为一行，地名、精度、上次定位时间与估算说明移至设置。无位置、关闭或自动定位未成功时不显示占位。

## 定位授权

- 首次主动点击时申请系统或浏览器定位权限，允许后获取实际经纬度；Mac 先等待应用进入前台，再发起授权。
- 区分尚未申请、已拒绝、系统定位关闭和设备限制。Mac 已拒绝或系统定位关闭时提供“打开定位设置”，恢复后可重新检查；系统已拒绝后不能强制重弹授权。
- 自动刷新不申请新权限，不持续追踪；自动定位坐标继续只留在当前会话，手动国内地点仍可离线计算。

## 下载与验证

Mac 提供 Apple 芯片 arm64 包，最低配置为 macOS 13；仍为 **ad-hoc 本地签名，未通过 Apple Developer ID 签名或 Apple 公证**。可通过“设置 → 关于”更新，或从正式 Release 下载 ZIP 后退出旧版并替换应用。

覆盖类型、状态、权限策略、构建与真实 WKWebView 隔离检查，以及浅深色、紧凑布局、更新和定位恢复的浏览器模拟。实际系统首次授权弹窗与真实位置精度仍需人工使用验收，不将模拟或隔离检查当作真实授权成功。长期驻留、真实登录、最低系统、多屏、完整跨版本安装重启、手机 Safari 与 iOS 真机仍未完整验收。
