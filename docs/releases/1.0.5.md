# i日历 1.0.5

本次完善版本与发布工具，接入 release-it，统一多端版本准备和标签推送。

## 更新内容

- release-it 从根清单读取当前版本，统一递增根包、共享核心、共享界面、Tauri、Cargo 与当前版本文档；Cargo.lock 由 Cargo 更新，其他文件统一格式化，全程沿用 pnpm。
- 发布前检查 main 分支、仓库身份、干净工作区、现有版本一致性、正式版本递增和已提交的中文说明，完成全量检查、Mac 构建与真实应用冒烟后才创建发布提交和附注标签。
- 原子推送 main 与当前版本标签，正式构建、更新签名、Release 附件、更新清单和官网仍由唯一 GitHub Actions 流程交付。
- 提供无写入的预演命令；质量门禁或推送失败保留现场，不自动硬重置工作区或删除远端标签，并补充操作与恢复说明。
- Mac 桌面会话检查前置：锁屏或缺少本机桌面时，在同步版本前停止并提示解锁，不改变系统锁屏设置。
- 原生冒烟改为有超时上限地等待真实窗口终点连续稳定，保留中间帧、最终坐标、透明度与隐藏状态断言，避免仅凭固定睡眠推断动画已结束。正常应用的动效与时长保持不变。
- 隔离冒烟不再受外部桌面失焦触发的自动收起干扰，仍显式验证收起、重开与旧失焦请求保护；正常应用继续失焦收起。

## 下载与更新

- Mac 包仅提供 Apple 芯片 arm64，配置最低 macOS 13；当前验证环境为 arm64 / macOS 15.7。Intel 与 iOS 安装包尚未提供。
- 已安装正式版可在“设置 → 关于”检查更新，确认后下载、验签并安装；也可下载 `i-calendar-1.0.5-mac-arm64.zip`，退出旧版后替换固定位置的 `i日历.app`。
- **Mac 包仍为 ad-hoc 本地签名，未通过 Apple Developer ID 签名或 Apple 公证。** 请从官方 Release 下载并核对 `SHA256SUMS.txt`，不要关闭系统全局安全保护。
- 自动更新继续使用原公钥和正式更新地址。

## 验证范围

隔离 Git 仓库覆盖预演不产生文件或引用变更、各端版本同步、中文提交和附注标签、原子推送、版本/说明/工作区校验，以及门禁和推送失败时保留现场。正式发布继续执行共享核心与界面测试、ESM/网页构建和真实 Mac 应用的普通与后台启动检查。

长期驻留、真实登录项、最低系统、完整跨版本安装重启、多屏矩阵与 iOS 真机尚未完整验收，不把隔离冒烟或工具验签等同于这些项目的完整实测。
