# i日历 2.5.3

月历中的今天、选中日期和鼠标悬停现在使用同一道干刷笔迹。今天使用浓主题色，选中的其他日期使用浅主题色。鼠标移过普通日期时会出现淡灰笔迹，移开后淡去。光标经过今天或已选日期时，两者各自的颜色仍然清楚。

主题设置里的月历预览也会显示选中日期的浅色笔迹。键盘选日时保留焦点轮廓，触屏点选直接显示选中状态。

## 下载和更新

已安装 Mac 版可在「设置 → 关于」点击「检查新版本」。安装包适用于 Apple 芯片（arm64）和 macOS 13 或更新版本，采用 **ad-hoc 本地签名，尚未通过 Apple 公证**。
