# i日历 2.0.0

主题现在导出为标准 ZIP，继续使用 `.icaltheme` 扩展名。可以用常见的 ZIP 工具查看包内文件。

## 主题包

- 配色和背景设置放在 `theme.json`。本地背景以独立 JPEG 文件随包分享，图片强度和裁切位置会一同保留。
- 在线背景继续保留 HTTPS 图片链接。纯色主题仅包含配置文件。
- 已安装的主题可以继续使用。旧版纯色、本地图片和在线图片主题包仍可导入。
- 新导出的 ZIP 主题包需要 i日历 2.0.0 或更新版本。使用 i日历 1.4.0 的用户可保留原来的 JSON 主题包。

## 下载

Mac 安装包适用于 Apple 芯片（arm64），最低系统要求为 macOS 13。应用采用 **ad-hoc 本地签名，未通过 Apple 公证**。

- [下载 Mac 安装包](https://github.com/cixiangtao/i-calendar/releases/download/v2.0.0/i-calendar-2.0.0-mac-arm64.zip)
- [打开网页版日历](https://cixiangtao.github.io/i-calendar/)
