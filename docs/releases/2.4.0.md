# i日历 2.4.0

今天的日期详情可以摇一支每日签。日期计算也换上了与主日历一致的日期选择器。

## 每日签

- 在今天的日期详情里展开「每日签」，点击签筒抽签。签面有生活灵感，也会展示当天的传统宜忌。
- 抽签结果保存在当前设备，今天再次打开时可以继续查看。

## 选日期与看详情

- 日期计算的起始日期和结束日期都可以从日历中直接选取。选择器支持切换年份、月份和快速选中今天。
- 主日历明确区分当前选中的日期和今天，调整了月份切换控件与日期详情摘要，让信息更紧凑。

## 下载和更新

已有版本可在「设置 → 关于」检查更新。Mac 安装包适用于 Apple 芯片（arm64）和 macOS 13 或更新版本。应用采用 **ad-hoc 本地签名，尚未通过 Apple 公证**。
