# i日历 1.3.2

本次按维护版交付，主要完善发布与验收流程。日历、日出日落、定位授权和应用更新交互沿用 1.3.1，没有新增面向用户的功能。

## 发布与验收

- 本地发布遇到锁屏或暂时没有可用桌面时，窗口检查单独记录待验，其他测试、构建与正式发布继续进行，减少反复解锁造成的中断。
- 待验记录绑定原应用路径与二进制 SHA-256，桌面可用后可补验同一产物；产物被覆盖时拒绝沿用旧记录。
- 补验仍遇到锁屏时保留已有结果及原始错误，不把待验记为通过。真实测试失败继续阻止流程，云端正式窗口检查保持严格执行。

## 下载与更新

- Mac 提供 Apple 芯片 arm64 包，最低配置为 macOS 13；Intel 与 iOS 安装包尚未提供。
- **Mac 仍为 ad-hoc 本地签名，未通过 Apple Developer ID 签名或 Apple 公证。** 请从官方 Release 下载并核对 `SHA256SUMS.txt`。
- 可在“设置 → 关于”检查更新，或下载 `i-calendar-1.3.2-mac-arm64.zip` 后退出旧版并替换应用。

## 验证边界

正式交付执行全量检查、原生测试、Mac 构建、云端 WKWebView 检查，以及公开下载包、更新源和官网核对。本机锁屏时单独保留窗口待验记录，不替代为通过；具体结果见仓库验证记录。

实际首次系统定位授权弹窗、真实位置精度、长期驻留、真实登录、最低系统、多屏、完整跨版本安装重启、手机 Safari 与 iOS 真机仍未完整验收。
