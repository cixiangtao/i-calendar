# i日历 1.4.0

这一版支持在线主题背景，调整了 Mac 月历上的设置入口，并让菜单栏可以直接打开日期计算和关于页。

## 主题

- 可粘贴 HTTPS 图片直链作为背景，调整图片强度和裁切位置。导入、导出主题包时保留原链接，离线或无法加载图片时使用主题底色。本地图和旧版主题包仍可使用。
- Mac 的月历、设置和日期计算共享主题画布。网页版将背景图铺在首屏日历工作区。默认「清爽白」使用原配色和纯色背景。
- HEX 和 RGBA 使用同一行配色表单，窄窗口也能编辑。图片强度与裁切采用统一滑动条，旧主题包中的 RGB(A) 和 HSL(A) 色值仍可读取。

## Mac 月历与菜单栏

- 月历右上角的齿轮直接进入设置。显示或隐藏日期详情时，齿轮位置一致。
- 菜单栏右键菜单使用「打开」「设置」「日期计算」「关于 i日历」和「退出」。「日期计算」可直接打开工具，「关于 i日历」展示品牌图标、版本与数据来源。
- 修复窗口滑出屏幕后在部分场景无法重新展开的问题。开发版与正式版可同时运行，两边分别保存偏好和缓存。
