# i日历 1.3.3

修复定位等待时按钮文字过淡的问题，并完善取消与权限设置入口。

## 按钮与定位等待

- 修复主按钮禁用时灰字叠加半透明主题底导致文字难以辨认的问题。普通禁用按钮使用可读的中性配色，等待中的主按钮保留主题底、清晰文字和加载标识。
- 定位等待时可点击“取消定位”，立即恢复操作；旧请求迟到后不会覆盖新的定位或手动选择。
- Mac 始终显示“打开定位设置”，无需等到失败后才出现；等待中点击会先取消请求，再打开系统定位隐私页。
- 沿用既有系统授权与定位流程，未增加后台追踪。已被系统拒绝时仍需在系统设置中恢复权限，应用不能强制再次弹出授权框。

## 下载与验证

Mac 提供 Apple 芯片 arm64 包，最低配置为 macOS 13；仍为 **ad-hoc 本地签名，未通过 Apple Developer ID 签名或 Apple 公证**。可从“设置 → 关于”检查更新，或下载正式 Release 的 ZIP 后退出旧版并替换应用。

检查覆盖类型、状态、取消与迟到结果、浅深色主题下的禁用/等待文字对比度、原生 WKWebView 与定位设置 IPC 隔离保护，以及正式产物签名、摘要、更新源和官网。模拟定位和隔离检查不代表已验证实际系统首次授权弹窗或真实定位精度。

长期驻留、真实登录、最低系统、多屏、完整跨版本安装重启、手机 Safari 与 iOS 真机等既有人工验收边界继续保留。
