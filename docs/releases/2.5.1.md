# i日历 2.5.1

月历用一道随主题变色的干刷笔迹标出今天。笔迹同时衬托公历数字和下方的农历、节气或节日。点选另一天时，浅色底跟随选中的日期，笔迹留在今天。

放假日去掉了整格底色，保留红色日期和右上角的“休”字。遇到连续假期，可以沿着角标查看放假范围。补班日由“班”字标明。

## 下载和更新

已有版本可在「设置 → 关于」检查更新。Mac 安装包适用于 Apple 芯片（arm64）和 macOS 13 或更新版本。应用采用 **ad-hoc 本地签名，尚未通过 Apple 公证**。
