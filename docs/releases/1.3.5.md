# i日历 1.3.5

修复自动定位已获授权、却在收到旧位置时提前结束的问题。

## 自动定位

- 系统先返回过期缓存或无效坐标时，i日历会在同一次请求内等待新位置。取得有效坐标、取消或超时后即停止接收位置。
- 按收到坐标的时间判断位置是否有效，查找区县、道路或附近地名所花的时间不会让有效位置被误判为过期。
- 已开启定位权限的用户可在“设置 → 常规 → 日出日落”点击“重新定位”或“使用当前位置”。若系统在时限内仍未提供有效位置，可稍后重试或手动选择城市、区县。
