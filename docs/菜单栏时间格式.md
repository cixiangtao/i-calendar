# 菜单栏时间格式

Mac 菜单栏默认在图标旁显示 `HH:mm`。打开日历右上角设置，或右键菜单栏入口进入设置，在“菜单栏”标签的“菜单栏显示”中更改。开关和格式均在本机保存。

## 图标与时间

“显示图标”和“显示菜单栏时间”支持三种组合：

| 显示图标 | 显示时间 | 菜单栏效果                     |
| -------- | -------- | ------------------------------ |
| 开启     | 开启     | 图标和时间（默认）             |
| 关闭     | 开启     | 仅时间，点击时间仍打开日历     |
| 开启     | 关闭     | 仅图标，保留原来的时间格式偏好 |

至少保留图标或有效的时间文字，最后一个可见入口不能关闭；要从“仅时间”切换为“仅图标”，先开启图标再关闭时间。隐藏图标时，`[]`、`[ ]` 等空白输出格式不能应用。关闭时间或已保存格式没有有效文字时，图标开关保持开启。

旧设置没有图标字段时默认开启，沿用已有时间开关和格式。图标恢复后继续使用 macOS 单色模板，适应系统明暗外观；隐藏图标只移除图片，保留同一个菜单栏入口的文字、点击与右键菜单。

## 预设与自定义

| 预设             | 格式                 | 显示示例            |
| ---------------- | -------------------- | ------------------- |
| 时分（默认）     | `HH:mm`              | 08:05               |
| 时分秒           | `HH:mm:ss`           | 08:05:09            |
| 日期、星期和时间 | `MM月DD日 ddd HH:mm` | 11月12日 周四 08:05 |
| 12 小时制        | `A hh:mm`            | 上午 08:05          |

选择预设会立即应用并保存。选择“自定义”，输入后先查看实时预览，再点击“应用格式”；也可按回车应用。非法输入只显示错误，不覆盖已保存的格式。预览与实际菜单栏均跟随 Mac 系统时区，日历查询仍采用北京时间。

支持以下格式符，区分大小写：

| 格式符         | 含义                                        |
| -------------- | ------------------------------------------- |
| `YYYY` / `YY`  | 四位年 / 两位年                             |
| `MM` / `M`     | 月份，补零 / 不补零                         |
| `DD` / `D`     | 日，补零 / 不补零                           |
| `ddd` / `dddd` | 周四 / 星期四                               |
| `HH` / `H`     | 24 小时制，补零 / 不补零                    |
| `hh` / `h`     | 12 小时制，补零 / 不补零；午夜与中午显示 12 |
| `mm` / `m`     | 分钟，补零 / 不补零                         |
| `ss` / `s`     | 秒，补零 / 不补零                           |
| `A`            | 上午 / 下午                                 |
| `[文字]`       | 固定文字，不解析其中的格式符                |

例如 `MM月DD日 ddd HH:mm:ss` 显示 `11月12日 周四 08:05:09`；`[i日历] HH:mm` 显示 `i日历 08:05`。中文、空格和常用标点可直接输入，固定英文应放入方括号。格式不使用 `%H:%M` 形式。

格式上限为 48 个 UTF-16 代码单元，与输入框长度限制一致；空白格式、换行、控制字符、未闭合方括号及不支持的格式符会被拒绝。较长内容会占据更多菜单栏空间，建议保留常用信息。

## 刷新与保存

- 时钟由 Mac 原生线程维护，不依赖弹窗中的 JavaScript 定时器。弹窗收起后继续刷新。
- 包含 `s` 或 `ss` 格式符时按下一秒边界刷新，其余按下一分钟边界刷新；`[ss]` 这样的固定文字不会触发秒级刷新。时间文字只在实际变化时写入菜单栏。
- 设置修改会立即唤醒原生时钟；重新打开日历与原生恢复事件也会触发刷新。
- 格式与开关随日历偏好在本机保存。旧记录缺少全部菜单栏设置时自动采用图标和时间均开启、`HH:mm` 默认值；只缺少图标字段时补齐开启，不改变已有存储版本。
- 此功能仅在 Mac 显示；Web 和 iOS 继续复用日历界面，不显示 Mac 菜单栏时间设置。

TypeScript 预览与 Rust 实际输出使用同一份格式和显隐样例校验。已打包的 Mac 冒烟实例通过真实菜单栏 API 验证收起弹窗后持续跳秒，并读取原生状态检查图文、仅时间、仅图标以及图标模板恢复；该实例不读写用户偏好。完整检查范围见[验证记录](验证记录.md)。
