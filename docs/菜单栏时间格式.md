# 菜单栏时间格式

Mac 菜单栏默认在图标旁显示 `HH:mm`。打开日历右上角设置，或右键菜单栏图标进入设置，在“菜单栏时间”中更改。关闭“显示菜单栏时间”后保留图标与格式偏好，重新开启即可恢复。

## 预设与自定义

| 预设             | 格式                 | 显示示例            |
| ---------------- | -------------------- | ------------------- |
| 时分（默认）     | `HH:mm`              | 08:05               |
| 时分秒           | `HH:mm:ss`           | 08:05:09            |
| 日期、星期和时间 | `MM月DD日 ddd HH:mm` | 11月12日 周四 08:05 |
| 12 小时制        | `A hh:mm`            | 上午 08:05          |

选择预设会立即应用并保存。选择“自定义”，输入后先查看实时预览，再点击“应用格式”；也可按回车应用。非法输入只显示错误，不覆盖已保存的格式。预览与实际菜单栏均跟随 Mac 系统时区，日历查询仍采用北京时间。

支持以下格式符，区分大小写：

| 格式符         | 含义                                        |
| -------------- | ------------------------------------------- |
| `YYYY` / `YY`  | 四位年 / 两位年                             |
| `MM` / `M`     | 月份，补零 / 不补零                         |
| `DD` / `D`     | 日，补零 / 不补零                           |
| `ddd` / `dddd` | 周四 / 星期四                               |
| `HH` / `H`     | 24 小时制，补零 / 不补零                    |
| `hh` / `h`     | 12 小时制，补零 / 不补零；午夜与中午显示 12 |
| `mm` / `m`     | 分钟，补零 / 不补零                         |
| `ss` / `s`     | 秒，补零 / 不补零                           |
| `A`            | 上午 / 下午                                 |
| `[文字]`       | 固定文字，不解析其中的格式符                |

例如 `MM月DD日 ddd HH:mm:ss` 显示 `11月12日 周四 08:05:09`；`[i日历] HH:mm` 显示 `i日历 08:05`。中文、空格和常用标点可直接输入，固定英文应放入方括号。格式不使用 `%H:%M` 形式。

格式上限为 48 个 UTF-16 代码单元，与输入框长度限制一致；空白格式、换行、控制字符、未闭合方括号及不支持的格式符会被拒绝。较长内容会占据更多菜单栏空间，建议保留常用信息。

## 刷新与保存

- 时钟由 Mac 原生线程维护，不依赖弹窗中的 JavaScript 定时器。弹窗收起后继续刷新。
- 包含 `s` 或 `ss` 格式符时按下一秒边界刷新，其余按下一分钟边界刷新；`[ss]` 这样的固定文字不会触发秒级刷新。只有文字变化时才更新系统菜单栏。
- 设置修改会立即唤醒原生时钟；重新打开日历与原生恢复事件也会触发刷新。
- 格式与开关随日历偏好在本机保存。旧记录缺少此设置时自动采用启用及 `HH:mm` 默认值；本轮不改变已有存储版本。
- 此功能仅在 Mac 显示；Web 和 iOS 继续复用日历界面，不显示 Mac 菜单栏时间设置。

TypeScript 预览与 Rust 实际输出使用同一份格式样例校验。已打包的 Mac 冒烟实例通过真实菜单栏 API 验证收起弹窗后持续跳秒、关闭后标题清空；该实例不读写用户偏好。完整检查范围见[验证记录](验证记录.md)。
